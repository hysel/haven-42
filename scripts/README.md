# About this folder

You do not need anything in this folder to use the Haven 42 application.

These are internal build, test, validation, and maintainer tools. They remain
in the source repository so contributors can reproduce releases and security
checks. They are not a user menu, and they are not included in the standalone
Local LLM IDE Tools package.

- To use Haven 42, download the app package described in the main
  [README](../README.md).
- To configure Continue, Aider, or OpenCode, use the
  [Local LLM IDE Tools package](../packages/local-llm-ide/README.md).
- To contribute to Haven 42, start with [CONTRIBUTING.md](../CONTRIBUTING.md)
  and [test tiers](../docs/test-tiers.md).
