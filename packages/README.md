# Optional Haven 42 packages

The main Haven 42 application has its own portable download. Optional tools
that serve a different audience live here so they do not clutter the normal
app setup.

- [Local LLM IDE Tools](local-llm-ide/README.md) configures Aider and OpenCode
  to use a local Ollama model. Continue is legacy evidence only and is not
  configured, recommended, packaged, or requalified.
