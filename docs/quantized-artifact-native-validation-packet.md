# Quantized Artifact Native Validation Packet

This packet prepares later Windows Intel and native macOS quantized-artifact
cells. It grants no download, conversion, activation, catalog, or machine
authority. Every artifact remains outside the repository and Haven package.

## Required Record

Record an immutable source repository and commit, input digests, exact source
and derivative licenses, a pinned conversion toolchain and recipe, derivative
digest and size, exact runtime/OS/architecture/accelerator/driver compatibility,
context and full-offload requirements, and final, temporary, and reserve space.
Reject a moving revision, missing provenance, unknown license, unsupported
kernel, insufficient storage, or silent CPU fallback.

## Native Cells

- Windows Intel: preserve the existing failed SYCL baseline and do not convert
  it into authority. A later candidate must pass exact engine, model, recipe,
  full-offload, functional, quality, tool-use, cleanup, and rollback gates.
- macOS: select an exact Apple Silicon device, native runtime, model revision,
  and format. Linux, Windows, CUDA, HIP, and Intel evidence cannot transfer.

Exercise staging, atomic activation planning, post-selection health, automatic
known-good rollback, interrupted-conversion recovery, and exact partial-file
cleanup. Commit only sanitized summaries and never model bytes, local paths,
prompts, responses, host identities, or raw logs.
