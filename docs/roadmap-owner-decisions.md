# Roadmap owner decisions

Recorded 2026-08-04 after review by the repository owner. These decisions
classify work; they do not activate a runtime, installer, updater, workflow,
signing process, publication flow, dependency, or machine effect.

1. Comparative model promotion remains owner-deferred unless user-reported
   inconsistency creates a concrete need for broader scoring.
2. The seven unresolved external image-runtime license investigations are
   owner-deferred and non-blocking for Haven 42 because external provider
   software will not be bundled or redistributed with Haven.
3. Installer work may continue only as effect-free simulation and preparation.
   Real installation and machine modification remain unadmitted.
4. A future managed private-network Ollama profile should default to a locally
   generated private root and exact-IP leaf certificate. Advanced users may
   supply their own trusted certificate. Certificate generation and trust-store
   modification remain separately approved future effects.
5. Updater work may continue offline through verifier, lifecycle, and rollback
   preparation. Network checking, downloading, staging, and activation remain
   disabled.
6. Executable workflow work may continue through contracts and simulations;
   command or tool execution remains disabled.
7. Tauri and Rust remain unadmitted.
8. The owner approved and published the exact unsigned Windows
   `0.4.0-alpha.1` prerelease on 2026-08-05. Signing, notarization, stable or
   production promotion, and every future publication remain separately
   owner-gated.
9. Physical macOS evidence remains parked until appropriate hardware is
   available.
10. The current reviewed UI and security batch remains uncommitted and
    unpushed until a separate explicit commit authorization.

Any future change to these decisions must be explicit and must pass the
applicable security, privacy, lifecycle, native-platform, and evidence gates.
