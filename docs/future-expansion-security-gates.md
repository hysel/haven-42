# Future Expansion Security Gates

Three machine-readable contracts now preserve the security boundary for work that cannot be admitted from local preparation alone.

Semantic embeddings require an immutable model, license review, explicit download consent, provider separation, offline behavior, hardware capacity, quality comparison against the lexical baseline, injection isolation, and cleanup. Persistent libraries require a separately selected encrypted engine, a user-scoped OS credential store with no plaintext fallback, atomic migration and rollback, retention/deletion/backup/restore, key-loss preservation, uninstall choice, and native package parity.

Self-hosted search must retain the same bounded query, citation, SSRF, disclosure, and cleanup rules as external search. Multi-query research is capped at four candidate queries, requires visible approval for each, shares aggregate result/byte/time budgets, supports cancellation, and forbids autonomous or page-injected follow-ups.

Audio and video define candidate metadata shapes only. No provider, download, generation, artifact write, route, UI, registry entry, or package is admitted until an exact external provider profile passes all twelve promotion gates.
