LET'S GET STARTED

Welcome to Haven 42

Haven 42 helps you use AI on your own computer. The recommended setup checks what your computer can run and explains every download before asking permission.

  • Your chats stay in memory and are not saved by Haven 42.
  • Haven 42 does not change drivers, Windows settings, services, or automatic updates.
  • You will see what is needed and approve it before anything is downloaded.

Haven 42 treats attachments only as information for the AI to read. It never runs attached code. Supported files include plain text, Markdown, CSV, JSON, selected source-code formats, and PNG screenshots. Files stay in memory for this task and are removed when you clear or start a new task.
