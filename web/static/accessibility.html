Accessibility statement

Last reviewed: August 7, 2026

Haven 42 aims to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. This is a self-assessed target, not a claim of third-party certification.

What has been implemented

  • Keyboard access for navigation, setup, chat controls, forms, native dropdowns, attachments, and disclosures.
  • Visible focus indicators and minimum 44 by 44 pixel targets for primary interactive controls.
  • Navigation, main-content, complementary-content, heading, label, status, alert, and note semantics for assistive technology.
  • Text, warning, status, focus, and control-boundary colors checked against WCAG AA contrast thresholds.
  • Status information is provided with text as well as color. Connection errors identify and describe the affected field.
  • Reduced-motion and Windows forced-color preferences are supported.
  • Section help tours use labeled modal dialogs, keep focus within their controls, support Back, Next, Skip, close, and Escape, and return focus when dismissed.
  • Live resource information remains visible but screen-reader announcements are limited to no more than once per minute.

Known limitations

  • The interface has not yet been manually tested across NVDA, JAWS, VoiceOver, TalkBack, and their supported browser combinations.
  • Live system statistics use a polite status region, but that behavior has not been verified with every screen reader and browser combination.
  • Automated keyboard and responsive-layout checks do not replace a complete manual keyboard, zoom, and screen-reader review.
  • The setup wizard keeps keyboard focus within its visible controls while open. Escape closes it and returns focus to the application.
  • The section help tours have automated keyboard, focus, reduced-motion, and responsive-positioning coverage, but have not yet been manually verified with the full screen-reader matrix above.

Testing is ongoing. This section will be updated when additional barriers or validation results are identified.

Technical scope

Covered version
Haven 42 desktop application 0.4.0-alpha.1
Covered interface
The bundled local web interface, setup wizard, section help tours, chat, models, system, technical details, About page, and this statement
Automated browser coverage
A locally installed Chromium-family browser in headless mode on Windows, including narrow viewport and reduced-motion checks
Screen-reader coverage
No complete manual screen-reader and browser matrix has been recorded yet

Assessment approach

This statement is based on a repository self-assessment. The current checks include deterministic contrast calculations, static semantic and security checks, and a real-browser flow covering landmarks, focus visibility, control sizes, dialog dismissal, responsive behavior, and reduced motion. Manual testing with named screen readers has not yet been completed, so this statement does not claim that coverage.

Report an accessibility barrier

Use the Haven 42 problem form and begin the report title with Accessibility:. Describe what you were trying to do, what happened, and the browser or assistive technology you used. Do not include passwords, API keys, private prompts, or attached file contents.

Open the accessibility problem form

This Alpha project does not currently promise a response time. Reports will be reviewed as development capacity permits, and confirmed accessibility barriers will be tracked with the other Alpha issues.

To request a correction to this statement, use the same form and identify the section that needs an update.
